Given a string s, find the length of the longest substring that contains no duplicate characters.

Important:

Substring means characters must be continuous.
We only return the length, not the substring itself.

Example:

s = "abcabcbb"

Possible valid substrings:

abc
bca
cab

Longest length:

3
Important Concepts Learned

1. Substring vs Subsequence
   Substring:

Characters must be next to each other.

Example:

abcabcbb

abc ✅
bca ✅
cab ✅
Subsequence:

Characters can be selected from different positions.

Example:

pwke

From:

p w w k e w

is a subsequence, but NOT a substring.

2. The Main Idea

We need to scan the string character by character.

We create a window that contains the current substring without duplicates.

Example:

abcabcbb

Current window:

[a,b,c]

Length:

3

When we see:

a

again:

[a,b,c,a]

There is a duplicate.

So we remove characters from the left until the duplicate disappears:

Before:

[a,b,c,a]

Remove first a:

[b,c,a]

Now the window is valid again.

3. Sliding Window Technique

The algorithm uses two ideas:

Moving forward

We use a loop:

for(let char of s)

to check every character.

Shrinking the window

When we find a duplicate:

Remove characters from the beginning.

Example:

[a,b,c,a]

Remove:

a

Result:

[b,c,a] 4. Data Structure

We need a container to store current characters.

Simple learning version:

let window = [];

Example:

window = [a,b,c]

It represents our current substring.

5. Useful JavaScript Methods
   includes()

Checks if a value exists.

Example:

window.includes("a")

Result:

true
push()

Adds an item to the end.

Example:

window.push("d")

Before:

[a,b,c]

After:

[a,b,c,d]
shift()

Removes the first item.

Example:

window.shift()

Before:

[a,b,c]

After:

[b,c] 6. Algorithm Steps
Create an empty window.
let window = [];
Create a variable to store the maximum length.
let max = 0;
Loop through the string.
for(let char of s)
If the character already exists:

Remove characters from the left.

while(window.includes(char)){
window.shift();
}
Add the new character.
window.push(char);
Update the maximum length.
max = Math.max(max, window.length);
Return the answer.
Final Learning Solution
var lengthOfLongestSubstring = function(s) {

    let window = [];
    let max = 0;

    for(let char of s){

        while(window.includes(char)){
            window.shift();
        }

        window.push(char);

        max = Math.max(max, window.length);
    }

    return max;

};
Complexity

This solution:

Time Complexity:

O(n²)

because:

includes()

searches inside the array every time.

Better professional solution:

Use:

Set

instead of array.

Because:

Set lookup = O(1)

This improves the solution to:

Time: O(n)
Space: O(n)
