# 🧠 LeetCode & NeetCode Practice

This repository contains my journey of learning **Data Structures and Algorithms (DSA)** by solving problems from **LeetCode** and **NeetCode** using **JavaScript**.

The goal of this repository is not only to solve problems, but to deeply understand the concepts behind each solution, improve problem-solving skills, and build strong algorithmic thinking.

---

## 📚 About This Repository

For each problem, I try to:

* Understand the problem requirements
* Analyze different approaches
* Implement the solution using JavaScript
* Review and improve my code
* Write explanations and notes about the solution
* Learn from mistakes and debugging

This repository is a personal learning archive where I document my progress in algorithms and data structures.
