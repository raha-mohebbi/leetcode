Dynamic Array (Resizable Array) — Full Summary of Our Discussion
1. What was the question asking?

The problem asks us to create our own Dynamic Array (like Java ArrayList or C++ vector).

A normal array has a fixed size:

let arr = new Array(3);

It means:

capacity = 3

[ _, _, _ ]

If it becomes full:

[10,20,30]

we cannot add another element.

A Dynamic Array solves this problem:

When the array is full, create a bigger array, copy the old elements, and continue.

2. Why did we create a class?

We created:

class DynamicArray {

}

Because we want to create a new data type.

JavaScript already has arrays, but we want an array with extra behavior:

Add elements
Remove elements
Resize automatically
Track size and capacity

So our class represents a custom dynamic array.

3. Why do we need a constructor?

The constructor runs when we create an object.

Example:

let myArray = new DynamicArray(5);

The number 5 goes into:

constructor(capacity)

The constructor prepares the new object.

It creates:

capacity = 5

arr = [_,_,_,_,_]

size = 0
4. Constructor explanation

Code:

constructor(capacity) {

    this.capacity = capacity;

    let arr = new Array(capacity);

    this.arr = arr;

    this.size = 0;

}
this.capacity = capacity

We save the capacity.

Example:

new DynamicArray(5)

Now:

this.capacity = 5;

Why?

Because later we need to know:

How much space we have
When the array is full
How much to increase during resize
let arr = new Array(capacity)

We create the real JavaScript array.

Example:

capacity = 5

Creates:

[ _, _, _, _, _ ]
this.arr = arr

This connects the local variable to the class.

Before:

let arr

Only exists inside the constructor.

After:

this.arr

The whole class can access it.

Other methods can use:

this.arr[i]
this.size = 0

Important:

size is NOT the array length.

It means:

How many elements are actually stored.

Example:

capacity = 5

[10,20,30,_,_]

size = 3

We have 5 spaces, but only 3 real values.

5. The three important variables

Every Dynamic Array has these:

1. arr

The actual storage:

[10,20,30,_,_]
2. capacity

How many spaces exist:

capacity = 5
3. size

How many elements exist:

size = 3

Example:

capacity = 5

arr:

[10,20,30,_,_]

size = 3

Meaning:

We have 5 available places
We are using 3 places
6. get(i)

Code:

get(i) {

    return this.arr[i];

}

Purpose:

Return the value at index i.

Example:

[10,20,30]

get(1)

Index:

0  1  2
10 20 30

Returns:

20

Important:

get does NOT use a loop.

It directly accesses the index.

7. set(i,n)

Code:

set(i,n){

    this.arr[i] = n;

}

Purpose:

Change a value.

Example:

Before:

[10,20,30]

Call:

set(1,99)

After:

[10,99,30]

i = index

n = new value

8. pushback(n)

Purpose:

Add a new element at the end.

Example:

Before:

[10,20,_,_]

size = 2

Call:

pushback(30)

This line:

this.arr[this.size] = n;

means:

this.arr[2] = 30

Because:

size = 2

Result:

[10,20,30,_]

Then:

this.size++;

Because we added one element.

Before:

size = 2

After:

size = 3
Why do we check:
if(this.size === this.capacity)

Because the array may be full.

Example:

capacity = 3

[10,20,30]

size = 3

The number of elements equals the available space.

So we need:

resize()
9. resize()

The purpose:

Double the capacity.

Example:

Before:

capacity = 3

[10,20,30]

Create:

capacity = 6

[_,_,_,_,_,_]

Then copy old values:

[10,20,30,_,_,_]

Code:

let newCapacity = this.capacity * 2;

Example:

3 → 6

Create new array:

let newArr = new Array(newCapacity);

Creates:

[_,_,_,_,_,_]

Copy old values:

for(let i=0; i<this.capacity; i++){

    newArr[i] = this.arr[i];

}

Example:

Old:

[10,20,30]

New:

[10,20,30,_,_,_]

Replace the old array:

this.arr = newArr;

Now the class uses the bigger array.

Update capacity:

this.capacity = newCapacity;

Because:

Before:

capacity = 3

After:

capacity = 6
10. popback()

Purpose:

Remove the last element and return it.

Example:

[10,20,30]

popback()

We save:

let value = this.arr[this.size-1];

Because:

size = 3

last index = 2

So:

value = 30

Then:

this.size--;

The size becomes:

size = 2

Finally:

return value;

returns:

30
11. getSize()

Code:

getSize(){

    return this.size;

}

Returns how many elements we have.

Example:

[10,20,30,_,_]

size = 3

Output:

3
12. getCapacity()

Code:

getCapacity(){

    return this.capacity;

}

Returns total available space.

Example:

[10,20,30,_,_]

capacity = 5

Output:

5
