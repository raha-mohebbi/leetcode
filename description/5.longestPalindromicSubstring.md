Summary:

Algorithm steps:

1. Pick every possible start index.
2. Pick every possible end index.
3. Create the substring.
4. Check if it is a palindrome.
5. Save it if it is the longest one.
6. Return the answer.

This is the easiest approach to understand, but it is not the most efficient. The optimized solution uses Expand Around Center and reduces the time complexity from O(n³) to O(n²).
