Given a string s and a number of rows numRows, write the string in a zigzag pattern and then read it row by row.

Example:

s = "PAYPALISHIRING"
numRows = 3

The zigzag pattern:

P   A   H   N
A P L S I I G
Y   I   R

Reading row by row:

PAHNAPLSIIGYIR
Understanding the problem

At first, we might think:

"Can we split the string into groups and put them into rows?"

For example:

PAY
PAL
ISH

But this is wrong because zigzag is not a simple split.

The characters move in a pattern:

Row 0
  ↓
Row 1
  ↓
Row 2
  ↑
Row 1
  ↑
Row 0
  ↓
...

It is like an elevator moving between floors.

Main idea

We simulate the movement.

Imagine we have numRows arrays:

For example:

[
 [],
 [],
 []
]

Each array represents a row.

We go through every character and put it in the current row.

We need two variables:

1. Current row
let row = 0;

It tells us where we are now.

2. Direction
let direction = 1;

It tells us the movement direction.

1  -> moving down
-1 -> moving up
Movement logic

When we reach the bottom row:

Example:

row 2

we cannot continue down.

So we change direction:

direction = -1;

When we reach the first row:

row 0

we change direction again:

direction = 1;

Then we move:

row = row + direction;
Example walkthrough

Input:

PAYPALISHIRING
numRows = 3

Start:

row = 0
direction = 1
P

Put P in row 0:

row0: P
row1:
row2:

Move:

row = 0 + 1 = 1
A

Put A in row 1:

row0: P
row1: A
row2:

Move:

row = 2
Y

Put Y in row 2:

row0: P
row1: A
row2: Y

Now we reached the bottom.

Change direction:

direction = -1

Move:

row = 2 - 1 = 1

Continue until all characters are placed.

Finally:

row0 = PAHN
row1 = APLSIIG
row2 = YIR

Join them:

PAHN + APLSIIG + YIR

= PAHNAPLSIIGYIR
Final solution
var convert = function(s, numRows) {

    if (numRows === 1) {
        return s;
    }

    let rows = Array.from(
        { length: numRows },
        () => []
    );

    let row = 0;
    let direction = 1;


    for (let char of s) {

        rows[row].push(char);


        if (row === numRows - 1) {
            direction = -1;
        }
        else if (row === 0) {
            direction = 1;
        }


        row = row + direction;
    }


    return rows.flat().join("");

};
Complexity Analysis
Time Complexity

We visit each character once:

O(n)

where n is the length of the string.

Space Complexity

We store all characters in rows:

O(n)
Key Algorithm Idea

This problem is not about splitting the string.

It is about:

Current position + Direction + Boundary check

The algorithm is a simulation:

Take a character
↓
Put it in the current row
↓
Check if we reached the top/bottom
↓
Change direction if needed
↓
Move to the next row

This pattern appears often in algorithms where something moves through states.
