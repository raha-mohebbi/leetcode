We are given two non-empty linked lists representing two non-negative integers.
The digits are stored in reverse order. We need to add the two numbers and return the result as a linked list.

Example:

l1 = [2,4,3]
l2 = [5,6,4]

The lists represent:

342 + 465 = 807

The answer should be:

[7,0,8]
Important Concepts:
1. Linked List Structure

Each node has two parts:

Node {
    val: value,
    next: next node
}

Example:

2 -> 4 -> 3 -> null

Means:

{
  val: 2,
  next: {
    val: 4,
    next: {
      val: 3
    }
  }
}
val = current digit
next = pointer to the next node
2. Do not use reverse()

The input is already reversed.

Example:

2 -> 4 -> 3

means:

342

not:

243

So we process the list from the beginning.

3. Accessing Nodes

To get the current digit:

l1.val
l2.val

To move to the next node:

l1 = l1.next
l2 = l2.next

Example:

Before:

l1:
2 -> 4 -> 3
^

After:

l1 = l1.next
2 -> 4 -> 3
     ^
4. Carry Concept

Like normal addition:

  8
+ 7
---
 15

We store:

5

and keep:

carry = 1

for the next calculation.

5. Dummy Node

We create an empty starting node:

let dummy = new ListNode(0);

Because creating a linked list from zero is easier.

Example:

dummy -> 7 -> 0 -> 8

At the end we return:

dummy.next

because we don't need the empty node.

Algorithm Steps:
Create a dummy node.
Create a pointer (current) to build the answer list.
Create a carry variable.
Loop while:
l1 exists
l2 exists
or carry is not zero
Get values from both nodes.
Add them with carry.
Store the last digit using:
sum % 10
Update carry using:
Math.floor(sum / 10)
Move to the next nodes.
Return the result linked list.
Final Code:
var addTwoNumbers = function(l1, l2) {
    let dummy = new ListNode(0);
    let current = dummy;
    let carry = 0;

    while (l1 || l2 || carry) {
        let sum = carry;

        if (l1) {
            sum += l1.val;
            l1 = l1.next;
        }

        if (l2) {
            sum += l2.val;
            l2 = l2.next;
        }

        carry = Math.floor(sum / 10);

        current.next = new ListNode(sum % 10);
        current = current.next;
    }

    return dummy.next;
};
Key Lessons:
Linked Lists are not arrays; you cannot use methods like .reverse().
Use .val to access the current value.
Use .next to move through the list.
Always handle different list lengths.
Remember to handle carry after the last digit.
A dummy node simplifies linked list creation.
